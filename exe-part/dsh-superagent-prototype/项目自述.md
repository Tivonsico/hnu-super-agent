# dsh-superagent

> **仅供参阅的研究原型，并非 DeepSeek 官方产品。** 这份代码源自团队日常的开发工作，其中相当一部分工程实现由编码智能体完成。请把它当作研究代码，而不是可用于生产环境的软件：它可能仍含有缺陷，编码风格与工程实践也可能前后不一致。在自有环境中采用之前，请先审阅并按实际情况调整。
>
> 为便于公开发布，我们对它做过适配，因此它与团队内部版本、以及《Exploring Super-agent Design: Towards a More Autonomous Agent System》一文中所描述的实现并不完全一致。文中讨论的部分设计属于后续演进方向，本原型尚未实现。

dsh-superagent 是面向单个 GitHub 仓库的主动式编码智能体，以 [DeepSeek Harness](https://www.deepseek.com/en/harness/) 的一个扩展包（bundle）形式交付。它监听 GitHub，也可按需接入飞书。当获得许可的人向它分派工作时，它会开立一项工作，在专属的智能体会话与目录中完成，并在原对话里给出答复，例如提交一个拉取请求（pull request）。Web 控制面板集中呈现需要人工处理的事项。

它同时也是一种与智能体协作的方式：**尽可能少地占用人的注意力，尽可能多地交付价值。** 一个能够代整个团队行动的智能体，同样能够耗散整个团队的注意力，因此它只在被请求、或团队编写的规则允许时才行动，只在有人必须介入、或结果可被采用时才发声。[docs/000-理念.md](docs/000-理念.md) 阐述了这一原则，以及它对操作者提出的要求。

## 安装配置

安装步骤较多，因此由智能体陪同你完成。向你的编码智能体发出如下指令：

> 阅读本仓库的《安装配置.md》，并陪我一起完成 dsh-superagent 的安装配置。

它每次只提一个简短问题，一次性展示完整方案，随后完成全部安装与配置。[安装配置.md](安装配置.md) 是它所遵循的指引。
