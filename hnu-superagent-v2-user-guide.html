使用场景

某天早八，你正在上一节水课，老师突然往群里扔了四五个文件，说大家要参加一个xx比赛，具体内容看通知。你挨个下载（中途还有一个不知道下到哪个文件夹了），来回翻了二十多分钟，终于弄明白。原来就交一篇文章，自己写，不用组队，交给学委就行。

还没睡醒的你迷迷糊糊把材料丢给ai，转头就刷起了视频。过了好一会儿，你想起来稿子应该写完了。打开手机一看，稿子是写完了，可 agent 到底存哪儿了？你又翻了一轮文件夹，好不容易才找到。

七八天后，学委终于在班级群里发了提交链接。你已经忘了上回在哪儿找到的稿子，只好再翻一遍。然后打开那个贼慢的腾讯文档，等它加载，把姓名、班级、学号一个个填进去，再把文章交上去。终于交了！但是你也浪费了生命中的几个小时，打断了多次心流状态。

agent 能做什么：

  1. 1.一开始是默认权限，即agent不会主动检查你qq群里的任何消息，只有你在控制面板打开对于一个群的监听，他就会自动开始检测并执行任务。任务执行的每一步成果你可以自己审批，也可以让他自动运行到最后一步。第一版默认只对群主和管理员的消息做出反应，这个你也可以在面板调整。
  2. 2.当刚刚那个场景发生的时候，你不用切换任何软件，后台我们的super agent就已经自动帮你在执行了。如果老师后续改了方案，上传了新的文件，他会自动接收并且把新文件加到同一张 [工单] 里。他会根据你的习惯自动执行，比如你是一个对水课比较糊弄的人，他就会忽略文件里”可选小组合作，拿分高“的要求，转而使用更简单的个人完成模式。
  3. 3.文件做好了！他会在右下角提醒你，然后你打开文件审阅了一下觉得不错，然后给工单挂一个“监测班级群学委发布的，对应链接的任务”，按天轮询模式比较耗token但是更省事；手动模式，需要当学委真的发来链接时，你在agent控制面板点一下启动任务。
  4. 4.不过无论如何，他都会自己打开那个腾讯文档链接，把你早就提供好的姓名、班级、学号以及文件格式都倒腾好，帮你填进去，最后一步提交你来按。如果你特别信任大肥鱼的话，你也可以让他直接按了哦。
  5. 5.不仅如此，每天的消息都会通过 课程-群聊-工单-状态的方式完成关联，无论是小班课、实验课、报告、ppt，他都能帮你完成（因为主要部分是由deepseek harness大肥鱼完成的）。你在湖大有话说这个小程序里能访问到的信息，在我们这里都能看到并完成关联！快来探索新的功能吧！

未来展望：构建 HNU 插件社区

  1. 会写插件的同学可以把插件做出来、传上来，让其他同学下载使用。比如给学习通、雨课堂做个自动签到插件。hxd 把签到码发给你，你都不用起床， Agent 就能自己扫码。
  2. QQ 群、CSDN 和各种论坛里散落着不少学习资料、历年试卷和操作指南。大家可以把这些资料传到共享的向量数据库，也可以把自己踩过的坑、摸索出来的操作步骤写成 Skill。以后遇到同样的问题，搜一下，像装插件一样装到本地。你可以自己翻，Agent 也能在帮你干活时查。
  3. 欢迎任何同学给这个项目添砖加瓦！技术大牛也好，刚入门的小白也好，说说你能帮哪一块就行。愿意深入参与开发，我们欢迎。愿意拿出一点 Codex Plus 的额度帮忙跑开发任务，也欢迎。
